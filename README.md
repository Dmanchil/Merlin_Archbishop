# Шаблон Telegram-бота на aiogram

Шаблон использует aiogram 3. Токен бота и ID администраторов хранятся в `.env`.
Данные пользователей хранятся в SQLite в таблице `users`, а общие параметры бота — в таблице `конфиг`.
При первом запуске языки из старого `data/user_settings.json` переносятся в базу `data/bot.db`.

## Запуск в Windows

1. Создайте виртуальное окружение и активируйте его:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Заполните `.env`:

   ```env
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id,telegram_id_другого_администратора
   ```

   Чтобы узнать Telegram ID, воспользуйтесь ботом для просмотра своего ID.

4. Запустите бота:

   ```powershell
   python bot.py
   ```

## Структура

- `bot.py` — создание бота, диспетчера и запуск polling.
- `config.py` — загрузка и проверка переменных окружения.
- `handlers/` — обработчики сообщений; `/admin` доступна только указанным администраторам.
- `keyboards/` — клавиатуры бота.
- `services/database.py` — SQLite-база с таблицами `users` и `конфиг`.
- `localization.py` — русский и английский тексты интерфейса.
- `.env.example` — пример переменных; настоящий `.env` исключен из Git.

Настройки открываются кнопкой «Настройки» или командой `/settings`. По умолчанию используется русский язык.
Команда `/delete_me` удаляет данные текущего пользователя из `users` после inline-подтверждения.
Команда `/menu` показывает приветствие и inline-кнопки для заданий, очков вклада и персонажа.
Нажатие «Получить задание» показывает временное предупреждение с кнопками «Приступить» и «Назад»; оно удаляется через 30 секунд или сразу после выбора.
Файл базы данных создается при запуске и исключен из Git. Для общих параметров доступны методы `get_config` и `set_config` класса `SQLiteDatabase`.
Таблица `users` содержит столбцы `tg_id`, `language`, `church`, `sequence`,
`contribution`, `first_seen` и `history_of_games`. В `history_of_games`
хранится JSON-массив завершённых раундов RPS и партий крестиков-ноликов с
результатами, ходами и временем игры. При обновлении старая таблица `пользователи`
автоматически переносится в `users`, сохраняя ID и язык.
При первом запуске бот предлагает выбрать церковь; выбранное значение сохраняется
в `users.church`. Текст интерфейса и клавиатур доступен на русском и английском
языках в зависимости от пользовательской настройки.

Команда `/tictactoe` запускает крестики-нолики в чате с помощью inline-кнопок.
Игрок делает ход кнопкой на поле, бот отвечает ходом компьютера, а после игры
появляется кнопка для нового раунда.
Команда `/rps` запускает игру «Камень, ножницы, бумага»: выбор жеста и новая
игра доступны через inline-кнопки.
Команда `/setdifficulty` открывает меню настройки
сложности обеих игр с текущими значениями. Выберите игру и отправьте новое число
от `0` до `1`; `/cancel` отменяет изменение. В «Камень, ножницы, бумага»
сложность задаёт вероятность, с которой бот выберет жест, побеждающий игрока;
в остальных случаях бот выбирает случайный жест.

Сложность крестиков-ноликов хранится в таблице `конфиг` в поле `tictactoe_difficulty`
как число от `0` до `1`. По умолчанию используется `0.5`. Администратор может задать
значение командой, например, `/setdifficulty 0.7`. На каждом ходе компьютера это число
задаёт вероятность выбрать оптимальный ход через минимакс; иначе компьютер делает
случайный ход. Значение `0` означает случайные ходы, а `1` — всегда оптимальную игру.
